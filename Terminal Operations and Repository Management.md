# **Terminal Operations and Repository Management**

This note provides terminal commands and best practices for managing your repositories on **Hugging Face**.

## **Cloning Repositories**

**For Models:**
```bash
git clone https://huggingface.co/FreddieTree/<model-name>
cd <model-name>
```
**For Datasets:**
```bash
git clone https://huggingface.co/datasets/FreddieTree/<dataset-name>
cd <dataset-name>
```
**Using SSH:**
```bash
 git clone git@hf.co:FreddieTree/<model-name>
cd <model-name>
```
